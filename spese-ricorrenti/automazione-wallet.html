  13. Comparirà il blocco "Registra Importo pagati a Esercente"

Automatically log payments with Wallet

With this automation, every time you pay by tapping a card or pass saved in Wallet, your phone will prompt you to log the expense in Skurda — no need to open the app manually.

Watch the video walkthrough:

  1. Open the Shortcuts app
  2. Go to the Automation tab (bottom)
  3. Tap the + in the top right
  4. Search for and select Wallet as the trigger
  5. Choose which cards/passes to monitor (in this example: all of them)
  6. Leave all categories selected
  7. Leave Filter Merchants without applying any filter
  8. Select Run Immediately
  9. Leave Notify When Run turned off — or turn it on if you want to see when it runs, but I'd still recommend leaving it off
  10. Tap Next
  11. In the "Search actions" bar, type Skurda
  12. Select the Record Payment action
  13. You'll see the block "Record Amount paid to Merchant"
  14. Tap the Amount field: a suggestion saying "Shortcut Input" will appear above the keyboard — tap it to insert it
  15. Do the same for the paid to field: tap it, then tap "Shortcut Input" from the suggestion above the keyboard
  16. Both fields now show the generic "Shortcut Input" placeholder. Tap the first one (Amount) and, from the menu that opens, select Amount
  17. Tap the second one (paid to) and select Merchant
  18. Confirm with the blue checkmark in the top right

Done: from now on, every Wallet payment will be automatically logged in Skurda.

Enregistrez automatiquement les paiements avec Wallet

Avec cette automatisation, chaque fois que vous payez en approchant une carte ou un billet enregistré dans Wallet, votre téléphone vous proposera d'enregistrer la dépense dans Skurda, sans avoir à ouvrir l'application manuellement.

Regardez la vidéo avec toutes les étapes :

  1. Ouvrez l'application Raccourcis
  2. Allez dans l'onglet Automatisation (en bas)
  3. Appuyez sur le + en haut à droite
  4. Recherchez et sélectionnez Wallet comme déclencheur
  5. Choisissez les cartes/billets à surveiller (dans cet exemple : tous)
  6. Laissez toutes les catégories sélectionnées
  7. Laissez Filtrer les marchands sans appliquer de filtre
  8. Sélectionnez Exécuter immédiatement
  9. Laissez Notifier en cas d'exécution désactivé — ou activez-le si vous voulez voir quand elle s'exécute, mais je vous conseille quand même de le désactiver
  10. Appuyez sur Suivant
  11. Dans la barre "Rechercher des actions", tapez Skurda
  12. Sélectionnez l'action Enregistrer un paiement
  13. Le bloc "Enregistrer Montant payé à Marchand" apparaît
  14. Touchez le champ Montant : une suggestion "Entrée du raccourci" apparaîtra au-dessus du clavier — touchez-la pour l'insérer
  15. Faites de même pour le champ payé à : touchez-le, puis touchez "Entrée du raccourci" dans la suggestion au-dessus du clavier
  16. Les deux champs affichent maintenant le terme générique "Entrée du raccourci". Touchez le premier (Montant) et, dans le menu qui s'ouvre, sélectionnez Montant
  17. Touchez le second (payé à) et sélectionnez Marchand
  18. Confirmez avec la coche bleue en haut à droite

Terminé : désormais, chaque paiement via Wallet sera automatiquement enregistré dans Skurda.

Wallet-Zahlungen automatisch erfassen

Mit dieser Automation schlägt dir dein Handy bei jeder Zahlung mit einer in Wallet gespeicherten Karte oder einem Pass vor, die Ausgabe in Skurda zu erfassen — ohne die App manuell öffnen zu müssen.

Schau dir das Video mit allen Schritten an:

  1. Öffne die App Kurzbefehle
  2. Gehe zum Tab Automation (unten)
  3. Tippe oben rechts auf das +
  4. Suche Wallet und wähle es als Auslöser
  5. Wähle die zu überwachenden Karten/Pässe aus (in diesem Beispiel: alle)
  6. Lasse alle Kategorien ausgewählt
  7. Lasse Händler filtern ohne Filter
  8. Wähle Sofort ausführen
  9. Lasse Bei Ausführung benachrichtigen deaktiviert — oder aktiviere es, wenn du sehen möchtest, wann sie ausgeführt wird, aber ich empfehle dir trotzdem, es zu deaktivieren
  10. Tippe auf Weiter
  11. Gib in der Leiste "Aktionen suchen" Skurda ein
  12. Wähle die Aktion Zahlung erfassen
  13. Der Block "Betrag bezahlt an Händler erfassen" erscheint
  14. Tippe auf das Feld Betrag: über der Tastatur erscheint ein Vorschlag "Kurzbefehl-Eingabe" — tippe darauf, um ihn einzufügen
  15. Mach dasselbe mit dem Feld bezahlt an: tippe darauf und dann auf "Kurzbefehl-Eingabe" im Vorschlag über der Tastatur
  16. Beide Felder zeigen jetzt den allgemeinen Platzhalter "Kurzbefehl-Eingabe". Tippe auf den ersten (Betrag) und wähle im sich öffnenden Menü Betrag
  17. Tippe auf den zweiten (bezahlt an) und wähle Händler
  18. Bestätige mit dem blauen Häkchen oben rechts

Fertig: Ab jetzt wird jede Wallet-Zahlung automatisch in Skurda erfasst.

Hattest du Schwierigkeiten bei der Einrichtung? Schreib uns an feedbacksr@icloud.com.
